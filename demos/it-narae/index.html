사내 업무 시스템 구축

사내 업무를 화면으로 옮기는 일을 합니다.

엑셀과 종이 결재로 돌아가던 업무를 웹으로 바꿉니다. 회계나 생산처럼 이미 쓰는 시스템이 있으면 그쪽 데이터베이스와 붙여 같은 내용을 두 번 입력하는 일을 없앱니다.

구축이 끝나면 운영 인수인계 문서를 드립니다. 이관 후 3개월은 무상 보수 기간입니다.

사업 분야

그룹웨어와 사내 업무 시스템을 만듭니다.

  • 그룹웨어 구축

    30인에서 300인 규모 기준. 전자결재와 근태, 게시판, 일정 공유를 한 화면에.

    주요 기능

    • 전자결재
    • 근태 관리
    • 게시판
    • 일정 공유
    • 조직도
    • 결재선 설계

  • 업무 시스템 개발

    주문과 재고, 출하를 웹 화면으로. 요구사항 문서 3주 후 개발 착수.

    주요 기능

    • 주문 관리
    • 재고
    • 출하
    • 생산 실적
    • 현장 태블릿
    • 요구사항 정의서

  • 노후 시스템 이관

    10년 넘은 사내 시스템의 데이터 이관. 옛 화면은 두 달간 병행 운영.

    주요 기능

    • 데이터 이관
    • 중복 코드 정리
    • 화면 재구축
    • 병행 운영

  • 시스템 연동

    회계와 생산, 사내 메신저를 API 로 연결. 연동 문서가 있으면 3주.

    주요 기능

    • 회계 연동
    • 생산 연동
    • 메신저 알림
    • API
    • 전표 자동 전송
