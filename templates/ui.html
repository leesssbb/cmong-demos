허브 UI/UX 보드 레이아웃색

UI/UX 보드

레이아웃이 뼈대라면 여기는 살이다. 같은 레이아웃·같은 색이라도 모서리·그림자·테두리· 여백·그리드 열수가 달라지면 전혀 다른 사이트로 읽힌다. 아래 킷은 실제 수상작 CSS 를 재서 만든 것이고, 스튜디오에서 한 번 고르면 미리보기 전체에 적용된다.

실측 근거

UI 킷 종

같은 부품 묶음(제목·버튼 2종·카드 3개·목록·표)을 킷마다 다시 그렸다. 차이만 보면 된다.

업종별 처방

스튜디오에서 업종을 고르면 이 표대로 킷과 모션이 자동으로 잡힌다. 마음에 안 들면 직접 바꾸면 된다. 안티패턴은 하지 말 것이다. 의료는 법에 걸리므로 모션을 Subtle 로 묶어 둔다.
원본(ui-reasoning.csv)은 미국 기준이라 의료 업종에 후기를 넣으라고 조언한다. 한국에서는 의료법 56조 위반이므로 그 조각은 떼어냈고, 뗀 이유를 표에 남겼다.

업종킷모션권장 패턴피할 것
킷 수치는 research/design-refs/captured/ 의 사이트 CSS 를 직접 재서 뽑았다. 업종 처방은 ui-ux-pro-max ui-reasoning.csv 를 우리 업종에 이어 붙인 것이다. 다시 만들려면 python templates/_build/ui_kits.py.
